# M.O.B Signal

*Dark-mode web design system for engineering consoles. 0px border-radius, 4px grid rhythm, and green signal accent.*

## Overview

A dark-only web design system for engineering interfaces. Square geometry, a 4px spacing scale and dense tables use one green accent for actions, selection, focus and healthy status. Information uses blue; warning and failure use distinct semantic roles. Space Grotesk, Plus Jakarta Sans and JetBrains Mono are bundled locally with English and Vietnamese glyph coverage. Token values are defined in tokens.measured.json; CSS and compatibility exports are generated by the project build. Accessibility requirements are component-specific and supported by measured contrast, keyboard behavior and responsive tests.

### Voice and Tone
- **Adjectives:** precise, engineered, restrained, high-density
- **Tone:** Use sentence case for buttons, labels, table headers and navigation. Preserve the registered brand spelling M.O.B Signal exactly. Write actions as verb-first imperatives ("Deploy new service", "Save changes", "View audit log"), never ALL CAPS and never noun-only labels. Short, factual, no marketing superlatives; state the number instead of praising it.

### Messaging Pillars
- One accent, used with intent - one green #00cc5c marks the action, the selection, the focus and the healthy state, and nothing else gets it. What separates an action from a state is the word, the shape and the icon, not a second shade of green.
- Square architecture - strict 0px radius and 1px rules communicate precision; rounding anything reintroduces the generic SaaS look.
- Density with breathing room - high-information tables and panels on a 4px grid, with contrast and focus states doing the work that shadows usually take.
- Accessibility is the spec, not the pass - AAA on primary text and on accent fills, visible keyboard focus on every interactive element.

## Typography

Typography is engineered for maximum clarity, readability, and data density.

- **Display Font:** Space Grotesk (Weights: 500, 600, 700). Used for page titles and section headers with `-0.02em` tracking.
- **Body Font:** Plus Jakarta Sans (Weights: 400, 500, 600, 700). Used for UI controls, body copy, and metadata.
- **Monospace Font:** JetBrains Mono (Weights: 400, 500, 600). Used for commit hashes, code blocks, latencies, and technical values.
- **Tabular Figures:** `font-variant-numeric: tabular-nums` is mandatory on all metrics, counters, table columns, and timers to prevent layout jumps.
- **Localization:** Full Vietnamese diacritics coverage supported via bundled local variable fonts.

## Layout

Layouts adhere to a strict 4px modular spacing grid and fixed boundary arithmetic:

- **Base Grid:** 4px unit (Scale: 4, 8, 12, 16, 20, 24, 32, 40, 48px).
- **Component Sizing:** Control height 32px (Small: 28px, Large: 40px), Nav height 48px.
- **Layout Columns:** 12 columns with 24px grid gap.
- **Breakpoints:** 640px (sm), 768px (md), 1024px (lg), 1280px (xl), 1536px (2xl).
- **Containers:** Application maximum 1200px, prose maximum 920px.
- **Panels:** Sidebar 240px, Drawer 360px, Modal widths 480px / 640px / 880px.

## Elevation & Depth

Depth is achieved through surface luminance stepping and neutral black-only shadows. Colored glows, bloom, and tinted shadows are strictly prohibited.

- **Low Elevation (`shadow-sm`):** `0 1px 2px rgba(0, 0, 0, 0.4)`
- **Medium Elevation (`shadow-md`):** `0 4px 6px -1px rgba(0, 0, 0, 0.5), 0 2px 4px -2px rgba(0, 0, 0, 0.5)`
- **High Elevation (`shadow-lg`):** `0 10px 15px -3px rgba(0, 0, 0, 0.6), 0 4px 6px -4px rgba(0, 0, 0, 0.6)`
- **Focus Elevation:** `0 0 0 2px #0a0a0a, 0 0 0 4px #00cc5c` with transparent outline fallback (`outline: 2px solid transparent; outline-offset: 2px`) for Windows High Contrast Mode.
- **Z-Index Ladder:** 1 (raised), 10 (sticky nav), 40 (drawer), 50 (dropdown), 100 (modal), 110 (popover), 120 (toast), 130 (palette).

## Shapes

The defining brand trait of M.O.B Signal is strictly square geometry:

- **Border Radius:** `0px` everywhere. Buttons, inputs, cards, dialogs, badges, and avatars must not be rounded.
- **Border Width:** Standard `1px solid` rules. Selected indicators use a `2px` leading edge.
- **Artwork Exception:** Platform app icon backing plates (iOS/macOS icon plates) are permitted as artwork exceptions, but all UI elements remain square.

## Components

M.O.B Signal ships 28 foundational Radix UI headless primitives styled with Tailwind CSS v4, strictly 0px radius, and dark console tokens:

- **Actions:** `Button` (primary, secondary, outline, ghost, danger, link; sizes: sm, default, lg, icon; `asChild` slot delegation).
- **Form Controls:** `Input`, `Textarea`, `Label`, `Checkbox` (16x16 with green check fill), `RadioGroup` (square with solid inner square indicator), `Select` (custom square dropdown), `Switch` (square sliding toggle), `Slider` (horizontal range track with square thumb).
- **Data Display & Containers:** `Card` (Header, Title, Description, Content, Footer), `Table` (Header, Body, Row, Head, Cell; dense spacing with row hover and selection), `Badge` (operational, warning, error, info, neutral), `Avatar` (square with fallback initials), `Skeleton` (pulse placeholder), `Progress` (linear bar with green signal fill), `Separator` (1px horizontal/vertical divider), `AspectRatio`.
- **Navigation & Disclosure:** `Tabs` (TabsList, TabsTrigger, TabsContent with 2px green active underline), `Accordion` (collapsible sections), `Collapsible`, `Breadcrumb` (List, Item, Link, Separator, Page).
- **Feedback & Overlays:** `Alert` (default, info, warning, destructive with 4px colored left border), `Tooltip` (instant hover on elevated dark surface), `Dialog` (modal scrim with focus trap), `AlertDialog` (destructive action confirmation), `Sheet` (slide-out side drawer from 4 screen edges), `Popover` (anchored floating container), `DropdownMenu` (multilevel menu with checkboxes, radio items, and shortcuts).
- **Touch Targets:** Minimum 24px for fine pointers (mouse) and 44px for coarse pointers (touch) via centered pseudo-elements on 16px controls to preserve square visual density.
- **Status Indicators:** Multimodal signaling: always combine a 6px square marker + status text + icon at 14px+. Never use color alone to convey state.
- **Motion:** Scoped to 0.12s ease-out (`cubic-bezier(0.16, 1, 0.3, 1)`) on `background-color`, `border-color`, and `color`. Overlays use opacity fades (0.12s enter, 0.08s exit). All motion collapses to 0.01ms under `prefers-reduced-motion: reduce`.

## Do's and Don'ts

### Do
- **Do** enforce 0px border-radius on all UI controls and cards.
- **Do** use `#000000` text on primary green accent fills (9.79:1 AAA contrast).
- **Do** pair every status color with explicit status text and a geometric marker.
- **Do** use `font-variant-numeric: tabular-nums` for all dynamic numbers, timers, and metrics.
- **Do** maintain visible `:focus-visible` rings with transparent outline fallbacks for High Contrast Mode.
- **Do** respect `prefers-reduced-motion: reduce` by zeroing transition durations.
- **Do** use native semantic elements (`<button type="button">`, `<dialog>`, native inputs).

### Don't
- **Don't** round anything (no rounded-sm, rounded-md, pills, or circular badges).
- **Don't** use `transition: all`. Animate only `background-color`, `border-color`, `color`, and `opacity`.
- **Don't** add neon glows, bloom effects, radial gradient blobs, or colored shadows.
- **Don't** use white or `#ededed` text on `#00cc5c` (measures 1.83:1 and fails WCAG).
- **Don't** use fake buttons (`<a role="button">` without href or space/enter key handlers).
- **Don't** publish or allow a light theme; the system is strictly dark-only.
- **Don't** use `muted` (`#737373`) for 12-14px body text (measures 4.18:1, below 4.5:1 AA).
