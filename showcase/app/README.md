# M.O.B Signal UI kit

Editable local-data service console using shared M.O.B Signal components.

- index.html loads the shared token, component and overlay styles plus console.js.
- main.jsx and components/ contain the editable React source.
- console.css owns page composition; shared control recipes live at the project root.
- console.js and its license sidecar are generated by npm run build.

Start the package with npm start and open /ui_kits/app/. No runtime CDN is required.
The console filters and creates sample deployments; settings persist in this browser.
No real infrastructure is connected. Do not enter secrets.

Current design rules are in BRAND.md and tokens.measured.json. Historical source
references are not required or bundled. Supplied logos remain in logos/mob-logo/.
