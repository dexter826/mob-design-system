Grid and layout

One 12-column grid inside a 1200px app measure, 24px gaps, gutters from the 4px scale, a 240px docked sidebar that becomes a 360px overlay drawer, and a single ordered z ladder from 1 to 130. Nothing on this page invents a width — every width names a token.

Both measures are drawn at true width, so they stack instead of sitting side by side: 1200 plus 920 plus a gap exceeds the app measure, and shrinking the pair to fit would stop being a to-scale reference. Column bands are --color-surface-subtle with a 1px --color-border outline, and that rule computes to 1.31:1 on canvas — it is scaffolding, never the sole carrier of meaning, so the digit inside each band is what states the column. Below 768px this preview collapses to 4 tracks, matching the sm row of the table.

Gutter steps 48 → 24 → 16 (--gutter, --mob-signal-gutter-md, --mob-signal-gutter-sm) and columns step 12 → 8 → 4; --columns publishes 12, so 8 and 4 are stated here as grid overrides at a named breakpoint, not as new tokens. Query the breakpoint tokens, never a bare number, so a media query can be audited against the contract. The drawer is an overlay and takes --z-drawer. The token contract registers no scrim colour; the wash lives in overlays.css, where a black element reaches its alpha through its own opacity so no literal hue is ever added to a sheet.

Popover and tooltip are maximums: shorter content sets its own width, longer content wraps rather than exceeding the cap. A second sidebar step is registered, --mob-signal-sidebar-wide at 280, for a filter panel with two-line labels. Any block wider than this card is clamped by max-width: 100%; the label states the true number and only the 1200 block is guaranteed full scale.

The numbers in the stage are printed for review only — a component that declares z-index: 100 is a bug even when the digit happens to match, because the ladder can then no longer be re-ordered in one place. Each block resolves its own token: --mob-signal-z-raised, --z-drawer, --z-modal, --z-popover, --z-toast. Two rules follow from the ordering: to open a modal over a drawer, close the drawer first; and if the ladder is ever exhausted, re-order it rather than adding a fourth digit. Depth is carried by the surface step and a 1px border, not by a shadow — the three elevation shadows are black-alpha and reserved for real floating surfaces. Note also that z-raised is the only step without a public alias, so a component must reach for the namespaced name.

Scroll either pane. Both bars are 48px and both carry --z-sticky. The left one is position: sticky, keeps the space it occupied in the flow, and needs no reserve. The right one simulates position: fixed with an absolute bar over scrolling content, so the content must start below the dashed line — a declared padding-top: var(--nav-height). Keep the height in one token so the chrome and the reserve can never drift apart. The source nav renders at 48px from 12px padding over a 24px line box, with its 1px bottom rule sitting outside the content height the token owns. Tab into either bar to see the focus ring (--mob-signal-shadow-focus: 2px canvas, then 4px accent) drawn without layout shift.

  • Fixed chrome reserves its own height instead of covering content.
  • One sticky element per axis per view — a header plus a footer plus a sticky sidebar is three ladders competing.
  • Content names a region token or spans columns; where no region token exists it caps with max-width rather than fixing a width.
  • Gaps come from --grid-gap and the gutter steps only — no per-section gap.
  • Numbers stay right-aligned in mono with tabular figures, so a column reads as a column at every breakpoint.
