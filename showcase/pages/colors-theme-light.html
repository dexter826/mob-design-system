Theme

No light theme

A light theme is not part of M.O.B Signal. The source defines one set of color values and no light-mode equivalents for them, so this card reports the absence instead of showing a light palette.

  • What the source definesOne theme: color-scheme: dark, background #0a0a0a, surface #121212, foreground #ededed. Every component value in design-tokens.json and design-system.css references the same charcoal ramp. There is no second token set, no theme attribute and no theme switch. The single value the source does not define is the accent: it is corrected to neon green #00cc5c, and the archive volt #10e569 is kept as a recorded provenance value.
  • What a light theme would needA canvas, surface, surface-subtle and surface-elevated step, two border steps, three text steps and four semantic states, each re-measured for light-mode contrast. None of those values exist in the source, so no light swatch is published.
