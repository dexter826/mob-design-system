Voice and copy

Content patterns

What a writer copies: the five voice rules the archive states, the seven sentence formulas of 5.1 built from them, the status map of 5.2 as real badges, and the formatting rules of 5.3 rendered as live values.

Every ratio on this card is measured, taken from BRAND.md 15 and context/contrast-measured.md, which recomputes WCAG 2.2 from the hex values. Nothing is quoted from the archive and nothing is estimated. No script runs on this page; the one interactive specimen is a native details reveal.

Five voice rules, with the pair each one decides

The five rules are the archive's own sentences, transcribed. The worked pair under each one is authored for this system — the formulas in 5.1 to 5.3 have no counterpart in the source.

  1. Rule 1

    Sentence case on every label, header, nav item and button

    Wants

    Create database

    Never

    CREATE DATABASE — and not Create Database either. Title case breaks the same rule twice.

  2. Rule 2

    Button text starts with a verb

    Wants

    View audit log

    Never

    Audit log — a noun on a button names the object, not the action, so the reader cannot tell what pressing it does.

  3. Rule 3

    Statuses read Operational, Degraded, Failed, Pending

    Wants

    Status: Degraded

    Never

    Having a rough time — and never a word from the list that the last check does not support. A stale check makes the status unknown, not Operational.

  4. Rule 4

    State the number instead of praising it

    Wants

    Deployed to 2 regions. Request latency 42ms.

    Never

    Blazing-fast, seamless deploys. — no measurement in it, so nothing a reader can check.

  5. Rule 5

    Line length under 80 characters, high density, minimal chrome

    Wants

    Rollback failed. The live commit is still 7f3ac2d.

    Never

    We want to make sure that every deployment you create is completely seamless from start to finish, so please take a moment to review the details below. — one line well past 80 characters, carrying rule 4's offence with it.

Sentence formulas as real fragments

Each fragment is built from the recipes in components.css — .card, .btn, .field, .input-field, .field-error, .kbd — so the sentence is read in the chrome it will ship in.

Status map, rendered

A hue never carries status alone: colour, word and marker ship together, and the word is real markup, never a tooltip. The ratio beside each badge is the word on its own fill; markers and edges are held to the 3:1 non-text floor instead. Size decides the icon: a 12px badge keeps the measured 6px square and nothing else, because a 16px glyph would grow it off its 2px 8px padding. The icon named under each badge is the pairing at 14px and above — a stat cell, a table row action, a toast, an empty state, a panel header. The accent is the one hue with a use limit: full-saturation green halates, so it never carries text below 14px, is never a large background wash and never gets a glow. A selected row keeps its word in #ededed on the tint and takes the accent as an edge; an Operational badge keeps its word in the accent at 12px on its own tint chip — the one exception the halation rule grants — and it has no claim to a button.

success · 6px solid square · icon i-check at 14px+ · badge, table cell, stat label

7.53:1 AAA — Operational word on its own 10% tint over #121212. It is the same green as a CTA beside it (#00cc5c, 9.23:1 on the canvas), deliberately: what separates a state from an action is the 6px square, the icon and the word. A second green would have measured 1.24:1 from the first, which is not a distinction.

Do not write this

  • Deployed!No exclamation marks. A finished action is not a celebration: "Deployed commit 7f3ac2d to 2 regions."

  • We're done!No first-person-plural cheer. Say what changed and leave the voice out of it.

  • Sorry, something went wrong on our end.Never apologise for the machine's behaviour. Report it and the next step: "Rollback failed. The live commit is still 7f3ac2d."

  • DegradedA status word with no marker. Pair it with the 6px square, and with the icon wherever a slot exists.

  • Blazing-fast, seamless, cutting-edgeA superlative with no measurement. Give the number instead: "Request latency 42ms in eu-central-1."

  • CREATE DATABASEAn ALL CAPS label. Sentence case, everywhere, including the button.

  • Audit logA noun-only button. Start with the verb: "View audit log".

  • 3 service(s) selectedNo parenthetical plural. "1 service selected" · "3 services selected".

  • Invalid inputNot an error message. Name the field's own terms and the constraint: "Region must be one of the 8 available regions."

Provenance

The five voice rules at the top of this card are measured — they are the archive's own sentences, transcribed from historical design input (not bundled). The sentence formulas in 5.1, the status map in 5.2 and the formatting rules in 5.3 are authored from those rules and from the vocabulary the source does supply; no source page states them, so cite them as this system's spec and not as a source fact. Two of the four contrast claims the archive quotes are wrong, and both are corrected by measurement rather than restatement: black on the accent as the archive names it — the volt #10e569 — measures 12.43:1, not the claimed 14.2:1, and 9.79:1 on the live accent, and muted on the canvas measures 4.18:1, not the claimed 4.6:1 — which is why muted appears on this card only as the Paused marker and never as a 12px word. Every other ratio printed above is read from context/contrast-measured.md, the output of context/contrast.mjs.
