  • Field geometryPadding 8px 12px, height 32px, radius 0px, 1px border #262626, fill #0a0a0a, text #ededed, placeholder #737373. These are the input values in design-tokens.json.
  • StatesHover raises the border to #383838. Focus sets the border to #00cc5c and adds the ring. The transition is 0.12s cubic-bezier(0.16, 1, 0.3, 1) on border-color and box-shadow. A valid field gets no color: #00cc5c is reserved for the Operational status of a service, not for a filled-in input, so validity is shown by the absence of an error and saved by the toast.
  • CopyLabels are sentence case and name the thing. The hint states the constraint, the error states the fix. No all-caps labels, no noun-only buttons. The primary label below is 14px #000000 on #00cc5c, the smallest size the accent is allowed to carry: at 100% chroma it halates, so accent-colored text never drops below 14px, and smaller accent text would need a rgba(0, 204, 92,.1) chip rather than bare canvas.
