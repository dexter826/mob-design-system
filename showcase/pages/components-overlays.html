Overlays and feedback

Every floating surface in one recipe sheet: modal, destructive confirm, drawer, menu, popover, tooltip, toast, command palette, plus the four static feedback patterns. Radius stays 0px. A scrim is black alpha with no blur. Motion is an opacity fade in and a shorter opacity fade out, and nothing else.

Operable overlays

Open one, press Escape, and watch where focus lands. It returns to the control that opened the layer. The modal traps Tab between its first and last control.

Modal

Trigger: click, or Enter and Space on the focused button. Layer z-modal. Enter 0.12s opacity, exit 0.08s opacity. Focus moves to the first field, Tab is trapped, Escape closes, focus returns to this button. role="dialog", aria-modal="true", labelled by the heading.

Destructive confirm

Trigger: click. Layer z-modal. Enter 0.12s, exit 0.08s, opacity only. Focus starts on Cancel, the safe control; Tab is trapped, Escape closes without acting and returns focus here. The confirm button carries the error border and never the accent fill.

Drawer

Trigger: click. Layer z-drawer, one step below the modal, and a drawer never stacks on a modal: open a dialog first and this trigger does nothing. Enter 0.12s, exit 0.08s, no slide. Same focus contract as the modal.

Dropdown menu

Service

Trigger: click, ArrowDown or Enter on a focused row control. Layer z-dropdown. Enter 0.12s, exit 0.08s. Arrow keys move between items, Home and End jump to the ends, typeahead matches the first letter, Escape closes and returns focus to the trigger, Tab closes and moves on.

Popover

Filter services

Two controls, one dismiss action. A popover may hold interactive content; a tooltip may never hold one.

Trigger: click. Layer z-popover, above the modal it may sit on. Enter 0.12s, exit 0.08s. Focus moves to the first control, Escape closes without applying, outside activation closes, focus returns to the trigger.

Tooltip

Shows the last successful health check, in UTC. Rollback is unavailable until a snapshot exists.

Trigger: pointer hover and keyboard focus. The second control is disabled, so the wrapper is the trigger and it is the focus stop. Layer z-popover. Enter 0.12s, exit 0.08s. Escape dismisses it. Text only, max width tooltip-max.

Toast

Trigger: click, or the menu and popover actions above. Layer z-toast, so a result stays readable while a dialog is open. Surface #202020 with shadow-lg, the measured .toast-box lineage. Enter 0.12s, exit 0.08s, dismiss at 6s or 10s with an action; hover pauses the clock. Focus is never taken. A failed action also stays in the audit log.

Command palette

Cmd KCtrl K

Trigger: click, or Cmd K and Ctrl K from anywhere. Layer z-palette, the top step. Enter 0.12s, exit 0.08s. Focus lands in the field; ArrowUp and ArrowDown move the active row, Enter runs it, Escape closes and returns focus here.

Overlay motion values

One rule, deliberately minimal. The source allows 0.12s on background-color, border-color and color and bans entrance choreography, so an overlay only changes opacity: no transform, no slide, no scale, no stagger. Exit is 67% of entrance because a dismissal should feel cheaper than an arrival. Nothing here changes a box size.

prefers-reduced-motion: reduce collapses motion-enter and motion-exit to 0.01ms in the token contract, so both fades stop instantly and every layer reaches the same open and closed state. No layout depends on a duration: the scrim is an opacity cap, not a blur; a hidden layer keeps its box; the drawer is anchored rather than translated: a sliding drawer would break the entrance-choreography ban, and the scrim, the exit ratio and the region widths are the values this system changes instead.
