Typography

Type scale

Two text families and one mono across seven documented steps, from 12px to 32px. Headings use Space Grotesk at weight 600 with -0.02em tracking, body copy uses Plus Jakarta Sans, and code, hex and measured values use JetBrains Mono.

  • OpenType featuresThe source applies font-feature-settings "cv02", "cv03", "cv04", "cv11", "tnum" on body, so every text node inherits them. They take visual effect only in a family that ships those features; in this stack that is JetBrains Mono.
  • Tabular numeralsfont-variant-numeric: tabular-nums is set on table cells in the source and belongs on any figure that changes value in place. Numeric columns are right-aligned, as in the block above.
  • MeasureBody copy is capped at 70ch here. The layout rule keeps body lines under 80 characters, while headings, tables and token lists use the full column width.
  • Accent textThe accent is neon green #00cc5c at full saturation, level with the info blue on the luminance band, and it halates at small sizes. It never carries text below 14px, is never a large background wash and never gets a glow. #000000 on the accent fill measures 9.79:1 at the button's 14px label; anything smaller in the accent sits on a rgba(0, 204, 92,.1) chip or becomes #ededed. The 12px accent eyebrow on these preview cards is documentation chrome and a recorded deviation, not a specimen to copy.
  • Heading scaleHeadings take steps of the published scale — 32, 24, 20 and 18px — at display weight 600. The scale runs 12, 14, 16, 18, 20, 24, 32px. 40px and 42px headings and 700 on a heading are placeholder-sheet values, not part of this system.
