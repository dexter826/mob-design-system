Components

Button

Five documented variants plus the keyboard focus ring. Padding 8px 16px, control height 32px, radius 0px, label at 14px weight 500, one 0.12s transition on background-color, border-color and color.

Primary

Fill #00cc5c, text #000000 at 9.79:1 (AAA), label weight 600. Hover #00e065 at 11.85:1, active #00b853 at 7.98:1 — each step clears 1.21:1 against the base, the floor for a state change a viewer can actually see on a 32px fill. Black is the only label color an accent fill takes — #ededed on #00cc5c measures 1.83:1 and fails. One primary action per view.

Secondary

Fill #181818, text #ededed, 1px #262626 border. Hover lifts the fill to #222222 and the border to #383838.

Ghost

Transparent fill, text #a1a1a1. Hover sets the fill to #181818 and the text to #ededed. The text never gets lighter than #ededed.

Danger

Transparent fill, text #ef4444, 1px rgba(239, 68, 68, 0.3) border. Hover adds rgba(239, 68, 68, 0.1) and moves the border to #ef4444.

Disabled

Opacity 0.4, cursor not-allowed, pointer-events none. The same rule applies to every variant and keeps the label readable in place.

Keyboard focus

Tab to this button. The ring is 0 0 0 2px #0a0a0a, 0 0 0 4px #00cc5c and adds no layout shift. On this card's #121212 fill the accent ring measures 8.73:1, well above the 3:1 non-text floor.

Copy

Labels are sentence case and verb-first: "Deploy new service", "Save changes", "View audit log", "Delete project". No all-caps text, no noun-only labels, no marketing superlatives.

  • GeometryRadius is 0px on every variant. Height is 32px from the source arithmetic: 8px + 14px line + 8px + 2px border. The source defines one control size, not a small/large scale.
  • Variants in the sourcedesign-tokens.json documents primary, secondary and ghost. design-system.css adds the danger variant and the disabled rule. Nothing beyond these five states is defined, so no spinner, link or split-button style is claimed here.
  • Saturation, not lightThe primary fill is the corrected neon accent #00cc5c, not a glow. At 100% chroma it halates, so the accent never carries text below 14px, and the 14px label above sits exactly at that floor. It is never used as a large background wash and never gets a glow, bloom or colored shadow. State change is the one 0.12s transition on fill, border and color.
  • Success is not a buttonNo variant takes a green fill to report a state. Operational now shares the accent's green, so a healthy result is a sentence with a 6px square and an icon in a toast or a badge — never a second green button competing with the action button beside it. A destructive action keeps the error hue, as above.
