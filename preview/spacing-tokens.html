Spacing tokens

One 4px base unit and nine usable steps: 4, 8, 12, 16, 20, 24, 32, 40, 48, with space-0 held at 0px. The bar below is drawn at the token value, so the row lengths are the real numbers.

For the two-value rows the bar shows the horizontal step. Control height is 32px, which is 8px + 14px line + 8px + 2px border. The bars are drawn in the accent #00cc5c because a 4px to 48px mark has to clear the 3:1 non-text floor and only the accent does that on this card (8.73:1 on surface); they are documentation ink, not a status marker, and no product surface may use the accent for a scale like this.

  • RuleSpacing comes from the scale only. Card padding 24px, button padding 8px 16px, input padding 8px 12px, table cell 12px 16px. Grid gaps in these cards are 16px, list gaps 8px, section margins 32px.
  • DensityHigh-information tables and panels stay on the 4px grid with tight rows, and contrast plus focus states do the work that shadows usually take. Density comes with breathing room, not with extra padding steps.
  • Off-scale in the sourceThree measured values sit outside the documented scale: the table header cell uses 10px 16px, the badge uses 2px 8px and the kbd uses 1px 5px. They are reproduced here as found, not corrected.
  • Shape is not spacingNo border-radius step appears on this card. 6px, 10px and 16px are neither spacing values nor radius values in this system — every radius step is 0px. The shape card carries the real values.
