Controls

The control half of the component contract, which the source archive never shipped. Recipes live in components.css and load from colors_and_type.css; this card holds no colour of its own and runs with no script.

Measured: text field anatomy and the tab bar (including the 2px bottom edge on the active tab — its geometry is the archive's, its colour is the corrected accent), plus the checkbox's 16px box and its accent reading. Everything else on this page is authored from the tokens and is this system's own spec — do not cite it as a source fact. Every specimen sits on a #121212 card, because an #0a0a0a control fill on the #0a0a0a canvas would leave a 1.31:1 hairline as the only thing identifying it, and WCAG 1.4.11 fails that.

Two focus recipes, never mixedButton-class controls take 0 0 0 2px canvas then 0 0 0 4px accent, the token --mob-signal-shadow-focus. A focused text field, like the one above, takes the accent border plus 0 0 0 1px instead, with no layout shift.

Radius 0px, including the radioThe source resets border-radius: 0 !important on every element, so a radio here is a square control with a square dot. That is the brand's whole point, not a missing token.

Keyboard operation

Every control on this page is reachable with Tab and Shift + Tab and shows the 2px/4px ring. Escape closes a layer that has focus and does nothing else; no control on this page is dismissed by a hue or a hover alone.
