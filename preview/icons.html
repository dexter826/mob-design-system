Assets

Icon set

Sixty-five glyphs on a 24x24 grid with a 20x20 live area, 1.5px stroke, butt caps, miter joins. Orthogonal edges and true 45 degree diagonals only: no arcs, no rounded joins, no circular blob anywhere in the family.

Authored brand work: the family belongs to this system. The source archive historical design input (not bundled) supplies no icons — one decorative <svg> in the whole reference page, no glyph sheet and no icon font. Sprite assets/icons/icons.svg, stylesheet assets/icons/icons.css, metrics --icon-size-sm / -md / -lg, --icon-stroke, --icon-gap in the contract.

Consumed as <svg class="mob-icon mob-icon--20" aria-hidden="true"><use href="../assets/icons/icons.svg#i-check"></use></svg>. The sprite is referenced by URL, so a page opened over file:// must inline the symbols instead; every surface in this package is served over http and uses the external reference.

Three sizes, no fourth step

16px inline

Inside a 14px label, inside a badge, in a table cell, in a nav row, before mono metadata. --icon-size-sm.

20px default

Control and navigation step: buttons, inputs, icon buttons, sidebar, tabs, toast, dropdown row. --icon-size-md.

24px loud

Empty state, drop target, hero metric, a status read at a distance. Never a fourth size between the steps. --icon-size-lg.

Icon and label pairing

One gap, 8px, from --icon-gap. The glyph centres on the 20px line; the label keeps its own line box and the icon never sits on the text baseline. The label carries the meaning in sentence case and starts with a verb — the icon repeats it, it does not replace it.

Rows above: .mob-icon-pair at the 20px line for controls, .mob-icon-pair--16 for the 14px label and table-cell step, .mob-icon-pair--cell where a column of numbers has to stay in alignment.

Status mapping

A hue never carries status alone. Every status is hue plus shape plus word, and the shape is the same shape at every size. Operational, Degraded, Failed, Pending, Paused are the only status words in this system.

Pending and Paused share the neutral hue because the palette registers no sixth status colour. The shape and the word carry the difference, which is exactly what the redundancy rule is for. .mob-icon--status-neutral on --muted is reserved for a disabled or inactive control, never for live status text — #737373 on #181818 is 3.74:1, which passes for a graphic and fails 4.5:1 for a 12px label.

Standalone icon buttons

No visible label, so the button carries aria-label and the glyph is hidden. Visual height stays the brand 32px, the pointer box is --target-min and 44px on coarse pointers. Tab through: the ring is --shadow-focus, 2px canvas then 2px accent, and it shifts no layout.

Where the control is a toggle, the state lives on the element — aria-pressed or aria-expanded — and the accent marks it. A tooltip never substitutes for the accessible name.

Don't

  • No emoji as a functional icon. A check mark typed as a character is not i-check: it lands in the wrong weight, the wrong colour and the wrong line box, and a screen reader reads it as prose.
  • No rounded joins, arcs or circles. A 4px corner on one glyph breaks the language the same way a 4px radius on one component does. stroke-linejoin stays miter, stroke-linecap stays butt.
  • No accent fill on a glyph. Icons inherit currentColor; the accent marks the action, the selection, the focus and the healthy state and nothing else. No baked colour in the sprite, no gradient, no glow, no colored shadow, no illustration.
  • No size between the three steps. 18px is not a size. Set the class, not a width attribute, not a font-size, not a transform.
  • No icon without a word when it carries status. Hue and shape are not enough; the badge, the row and the announcement all say Operational, Degraded, Failed, Pending or Paused.
  • No animation on a glyph. No draw-in, no morph, no dashoffset trick, no spin. A busy state uses the determinate bar plus the word, because the contract allows 0.12s on background-color, border-color and colour only.

Accessibility notes

  • Stroke is 1.5px measured at the 24px box and scales with the box: 1.25px at 20, 1px at 16. The live area keeps its optical weight across the three steps instead of the absolute line width, so nothing thickens inside a badge.
  • Glyphs are non-text graphics under WCAG 1.4.11 and need 3:1 against their surface. At --color-text on surface they clear it by a wide margin; --color-text-secondary is the floor. --muted is used only on a disabled control, where the exemption applies.
  • Default is decorative: aria-hidden="true" plus focusable="false" whenever the label is visible next to it. The icon then adds nothing to the announcement.
  • An accessible name is required in exactly three cases, and each has a class: a standalone icon button (.mob-icon-button, aria-label mandatory), a status icon read as part of the state (.mob-icon-status, always paired with the status word), and a selected or active marker (.mob-icon-marker-selected, where the state lives on aria-selected, aria-current or aria-checked rather than in the glyph).
  • No <title> inside the symbols. The name belongs to the control, so a title in the sprite would announce twice. Language is inherited from the host document and nothing in the family is language-dependent.
  • Colour is never the only channel: the status map pairs hue, shape and word, and a selected row pairs the accent with the check and the visible label.
  • Focus is the contract ring on the control, never on the glyph: --shadow-focus is 2px canvas plus 2px accent, which clears 3:1 against both #0a0a0a and #121212 and adds no layout shift.
  • Hit area is separate from the drawn box. The glyph is 20px inside a 32px control whose pointer target is --target-min (24px) and --target-touch (44px) on coarse pointers.

Left open on purpose

  • No spinner, no progress ring, no skeleton shimmer: no motion token covers anything outside the 0.12s colour transition, so a busy state is the determinate bar plus the word.
  • No per-file-type glyphs. i-file covers manifest, config and log; the type is the label's job, and a 26-glyph extension set would be a library, not a family.
  • No provider or product logos. They are trademarks and they are not square.
  • No filled variants and no stroke-weight variants. One weight, three sizes; the contract registers neither a second stroke token nor an outline/solid split.
  • No dark-on-light or light-theme pair. The system publishes one theme, so the family ships one colour behaviour: inherit currentColor.
